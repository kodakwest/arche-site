# Getting Started with Agent Governance

Agent governance starts with a small set of decisions that every workflow can apply consistently:

1. Classify the intent.
2. Identify the target systems.
3. Assign the risk tier.
4. Check the allowlist.
5. Require approval for external, production, or destructive actions.
6. Record the decision and the outcome.

For v0, keep the control plane lean. A policy file, an evaluator, and an append-only audit log are enough to move from informal tool use toward governed agent operations.
