Ecosystem Map (Arche Studio)

🏗️ Architect Chat hero screen
Default Landing. Onboard users, generate the one consistent agent template. Provides single-conversation UI for design generation. Output designs and JSON orchestration configurations.
HTML/JS · Single Chat UI · template engine
🚀 Arche Library the launchpad
Shows saved/exported agent designs. Card UI with prominent **deploy/launch action buttons** pointing to target harnesses (Codex CLI, agy CLI, Claude/Jules, GitHub Copilot, Azure DevOps).
HTML/JS · harness adapters · LocalStorage
🖥️ Control Plane deploy orchestrator
Manages deploy files, packages, and configurations. Controls the exact assets pushed to each harness, tying Library launches to structured files.
HTML/JS · File Manager · package bundlers
📊 Workbench adversarial tester
Prompt stress testing, adversarial feedback, and model iteration. Dual-model conversation UI (Model A ↔ Model B, teal vs violet) with turn counters, latency tracking, and pause/resume controls.
HTML/JS · Dual-Model chat · Token telemetry
⚙️ Arche Flows advanced orchestration
Advanced multi-agent orchestration configuration. Generates AGENTS.md files, skill trees, tool assignments, and SOP protocol definitions based on ai-engineer-coach patterns.
HTML/JS · AGENTS.md parser · SOP definer
🌐 archework.ai live
Marketing site + ecosystem nav hub. Hosts product pages, docs, roadmap, and diagrams. Navigation to all Arche Studio surfaces. CF Pages.
HTML · CSS · JS · Cloudflare Pages

Arche Studio Shell & Brand Overhaul top priority

#2

Architect Chat — Hero Screen next

Landing page default. Implementation of single chat UI with design generation output, structured agent template definitions, and provider routing config.

#3

Arche Library & Launch Adapters next

Saved agent card display with prompt launch triggers. Build adapters to pipe designs directly as context/prompts to Codex CLI, agy, Jules, and Copilot.

#4

Control Plane & Workbench Integration future

Integrate package manager UI into Control Plane and adversarial dual-model prompt tester into Workbench (Model A ↔ Model B side-by-side stream with telemetry).

#5

Arche Flows (AGENTS.md Orchestrator) future

Technical power-user screen. Define multi-agent workflows, compile to AGENTS.md, apply ai-engineer-coach SOP templates, and commit to Git automatically.
