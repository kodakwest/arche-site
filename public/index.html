Loop contract

The prompt becomes durable when it becomes a contract.

The loop contract is the enterprise artifact: it states what starts the work, what done means, what tools can be touched, how the answer is verified, when humans approve, and what gets remembered.

Trigger + goalEvery loop starts with a condition and ends only when a verifiable finish line passes.
Tools + permissionsTool access is scoped as a risk surface: read, write, execute, approve, and block.
Workers + isolationPlanner, executor, verifier, and governance agents operate inside sandboxes or worktrees.
Verifier stackDeterministic tests, policy checks, reviewer agents, and human gates compound confidence.
Memory + auditState persists outside the model. Every run leaves evidence.

Governance layer

Autonomy needs a boundary before it needs more agency.

AgentArche positions governance as the operating layer around the loop, not a compliance afterthought. The loop can act, but the control plane decides where it can act, when it must stop, and what it must prove.

01 :: PERMISSIONS

Tool access is policy

Allowed tools, blocked tools, read/write scopes, credential identity, rate limits, and irreversible action gates.

02 :: VERIFICATION

Checks stack, not guess

Tests and schemas first, heuristic checks second, independent AI review third, human approval at the edge.

03 :: MEMORY

State lives outside the model

The loop remembers prior runs, successful patterns, known failures, policy decisions, and open exceptions.

04 :: AUDIT

Every run leaves evidence

Trigger, inputs, tools, outputs, changed assets, verifier result, approvals, and escalation history.

05 :: ROUTING

Models are replaceable

The loop contract survives model churn by abstracting model choice behind route, fallback, and evaluation rules.

06 :: ESCALATION

Human gates stay explicit

Warn and quarantine inside the loop. Hard-fail at production deploys, external sends, payments, access changes, and merges.

Use cases

Start with repeatable work that has a finish line.

The strongest loops have a clear trigger, low blast radius, measurable ROI, and a verification path.

ENGINEERING

PR repair loop

Triggered by failed CI. Creates an isolated patch, runs tests, requests approval before merge.

PRODUCT

Voice-of-customer loop

Triggered by new feedback. Clusters themes, cites evidence, drafts backlog candidates.

GOVERNANCE

Agent evidence loop

Triggered by any autonomous run. Produces the run ledger and evidence pack.

SUPPORT

Escalation loop

Triggered by SLA risk. Summarizes account history, drafts the handoff, routes to owner.

FINANCE OPS

Invoice exception loop

Triggered by PO mismatch. Explains discrepancy, collects evidence, routes approval.

PERSONAL

Command center loop

Triggered each morning. Reviews calendar, email, tasks, notes, and builds the day plan.
